# Auto Login 自动登录插件

![插件图标](https://github.com/user-attachments/assets/49a17341-5eea-4e0c-97e6-ee73842329cd)

## 简介

Auto Login 是一款专为频繁登录网站用户设计的 Chrome 浏览器插件，支持自动识别图形验证码并一键填写账号密码，让登录变得高效、便捷。插件完全免费，支持个性化定制，助您节省宝贵时间。

---

## 主要功能

- 🚀 一键自动登录：预设账号密码，快速登录目标网站
- 🔍 图形验证码识别：自动识别并填写验证码
- 🛡️ 本地数据存储：所有账号信息仅保存在本地，绝不上传，保障数据安全
- 🛠️ 支持定制开发：可根据需求定制支持更多网站

## 安装与使用

1. 在 Chrome 浏览器中安装 Auto Login 插件
2. 打开插件设置页面，输入并保存您的用户名和密码
3. 访问目标网站，点击插件按钮即可自动登录
4. 插件会自动填写账号、密码，并智能处理图形验证码

---

## 安全性说明

- 插件采用本地存储机制，所有敏感信息仅保存在您的设备上
- 绝不上传、收集或分享任何用户数据
- 代码开源，欢迎审查

## 开发初衷

随着互联网服务的增多，频繁登录不同网站成为常态，尤其遇到图形验证码时更为繁琐。Auto Login 致力于简化登录流程，提升用户体验，让登录不再成为负担。
